Persistent memory for AI coding agents

A local-first memory layer that gives Claude Code, Codex, Cursor and more a searchable history of decisions across sessions.

Get started View documentation
mnemo init --agent=all

Durable observations

SQLite + FTS5 stores structured memories with tags, topic keys and review states — searchable across every session and project reset.

MCP tools

Agents call mem_save, mem_search, and mem_context natively — memories survive context resets, compactions, and new sessions automatically.

Multi-agent

Claude Code, Codex, Cursor, OpenCode and Pi share one project-scoped store — a single .mnemo marker activates every integration.
