Synchronize all local mnemo memory with the configured cloud backend. Requires cloud credentials configured via `mnemo setup cloud` (saved to `~/.config/mnemo/cloud.toml`) or the environment variables `MNEMO_CLOUD_URL`, `MNEMO_CLOUD_KEY`, and `MNEMO_CLOUD_CLIENT_ID` in the MCP server environment. The operation is idempotent: repeated calls safely upsert the same local mutations and skip this client's own cloud rows on pull.
