# mnemo v2.0.0 — a stable protocol and safer upgrades

Mnemo 2.0 brings two major improvements together: a complete, versioned protocol for memory operations across agents, and a transactional upgrade path designed to protect existing memories if an update fails.

## One protocol across agents

- Complete the public `mnemo/1` contract and use the same domain operations from the CLI, MCP server, and agent integrations. This keeps memory behavior consistent across Claude Code, Cursor, Codex, OpenCode, and Pi.
- Add a reusable Go client and canonical `mnemo://<project-id>/observations/<sync-id>` references, so observations can be shared without exposing local SQLite row IDs or machine-specific paths.
- Cover project, memory, observation, session, tag, capture, event, and portable archive operations through the versioned contract.

## Upgrades that protect your data

- Apply SQLite schema changes transactionally, with reversible migrations and a recovery point for the existing database.
- Keep the previous executable available while the new controller is checked. If migration or post-upgrade verification fails, restore the previous executable and database state automatically.
- Wait for queued durable memory commands to be acknowledged before replacing the controller. When the queue does not settle within the bounded grace period, cancel the update instead of silently dropping pending work.
- Verify real SQLite reads, durable command processing, and event acknowledgement before committing an upgrade. Recovery also covers interrupted upgrades and late deliveries from the previous controller.

These checks run as part of the normal update flow. Users do not need to migrate or repair SQLite by hand.

## Updating

Use the usual update command or the official installer:

```bash
mnemo update
```

```bash
curl -sSf https://raw.githubusercontent.com/jmeiracorbal/mnemo/main/install.sh | bash
```

The installer and `mnemo setup refresh` remain the single source of truth for agent setup: MCP registration, hooks, global instructions, and skills.
