# mnemo v2.0.0 — release notes

## Highlights

- Complete the versioned `mnemo/1` protocol contract and route CLI, MCP and agent integrations through the same domain operations. Add the public Go client and canonical resource references for portable memory and project operations.
- Make binary and SQLite upgrades transactional. Validate migrations before switching executables, retain a recoverable previous release, and automatically restore the prior executable when post-upgrade health checks fail.
- Drain durable commands before replacing the controller and verify SQLite reads, durable command processing and event acknowledgement before committing an upgrade.
- Improve recovery from interrupted upgrades, late legacy deliveries, controller startup failures and unacknowledged JetStream messages.

## Upgrade behavior

Updates now keep a recoverable previous executable and validate the new controller against the existing database and durable event queue. Unsafe schema changes or failed post-upgrade checks prevent the new version from being committed and trigger automatic recovery. No manual database repair is part of the normal update path.

The controller waits briefly for queued durable commands to finish before an update. If the queue does not drain within the bounded grace period, the update reports the pending work instead of silently discarding it.

## Installation and distribution

The latest stable release is installed through the official installer:

```bash
curl -sSf https://raw.githubusercontent.com/jmeiracorbal/mnemo/main/install.sh | bash
mnemo version
mnemo doctor --agent=all --path=.
```

The installer and `mnemo setup refresh` remain the single source of truth for agent setup: MCP registration, hooks, global instructions and skills.

## Release verification

- The tagged `main` commit must pass the release workflow's reusable CI verification, including Linux/macOS tests, Linux race tests, lint, vulnerability checks and native service upgrade/rollback checks.
- Release assets must include macOS/Linux binaries for amd64/arm64, SHA-256 checksums, and the scripts archive and checksum.
- After publication, verify the official installer in an isolated `HOME` and `MNEMO_INSTALL_DIR`, warning-free setup, `mnemo version` reporting `v2.0.0`, fresh project initialization, `mnemo doctor`, and an affected command end to end.
- Only after the assets exist, update the pinned stable examples in `install.sh` and the English, Spanish and Chinese READMEs to `v2.0.0`.
