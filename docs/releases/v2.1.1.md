# Mnemo v2.1.1 — controller health diagnostics

Mnemo 2.1.1 makes `mnemo doctor` verify that the installation-wide controller
and its JetStream service are reachable, in addition to checking agent setup
and the SQLite schema.

## Controller health and repair

- `mnemo doctor` now reports an error when the managed controller configuration
  is missing or the NATS/JetStream service cannot be reached. It prints the
  relevant endpoint and a `mnemo doctor --fix` repair command.
- `mnemo doctor --fix` refreshes the managed setup when the controller health
  check fails, then reruns diagnostics so a failed restart remains visible.
- Alternate `--home` and `--data-dir` diagnostics do not claim to manage the
  user's global controller.

This release changes diagnostics and repair behavior only. It does not change
the Mnemo protocol, public Go API, or database schema.
