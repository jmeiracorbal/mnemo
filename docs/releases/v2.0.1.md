# mnemo v2.0.1 — Go v2 module support

Mnemo 2.0.1 makes the public Go packages consumable under the module path required for a v2 module. The CLI, MCP server, protocol behavior, and stored data are unchanged.

## Go module path

- Declare the module as `github.com/jmeiracorbal/mnemo/v2` and update Mnemo's internal imports to use the same versioned path.
- Import the public client and protocol packages from `github.com/jmeiracorbal/mnemo/v2/client` and `github.com/jmeiracorbal/mnemo/v2/protocol`.
- Add no compatibility aliases or bridge packages; Go consumers should use the `/v2` import path.

Install the module in a Go project with:

```bash
go get github.com/jmeiracorbal/mnemo/v2@v2.0.1
```

The published `v2.0.0` tag remains unchanged.

## Downloads

The release includes binaries and SHA-256 checksums for macOS and Linux on amd64 and arm64, plus the scripts archive and its checksum.
