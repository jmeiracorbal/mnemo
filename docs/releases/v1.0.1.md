# mnemo v1.0.1 — release notes

## Fixes

- Restore compatibility with OpenCode v2 by migrating the bundled mnemo plugin
  to the v2 plugin API. Session context injection, context refresh after
  compaction, and durable session events now use OpenCode's v2 hooks.

## Installation and upgrade

Use the installer to install the latest stable release:

```bash
curl -sSf https://raw.githubusercontent.com/jmeiracorbal/mnemo/main/install.sh | bash
mnemo version
mnemo doctor --agent=opencode --path=.
```
